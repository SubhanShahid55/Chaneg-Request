# Change Request Tracker - Frontend Architecture & Implementation Specification

## Project Overview
Internal tool for software agencies to rapidly capture client change requests, attach scope/cost/timeline estimates, and dispatch an interactive client approval link.

## Tech Stack & Libraries
- **Framework**: React / Next.js App Router pattern (standalone single-page interactive application rendered via comprehensive modular components)
- **Styling**: Tailwind CSS, Lucide Icons, Shadcn UI patterns, Linear/Notion aesthetic (neutral grays, crisp borders, subtle elevation, confident Indigo `#4f46e5` accent)
- **Animation & Motion**: CSS keyframes, transitions, interactive count-up stats, slide-over drawer transitions, toast notifications
- **Data Layer**: TypeScript interfaces, 10 realistic mock change requests, Supabase TODO hooks
